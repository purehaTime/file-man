# file-man

Файловый менеджер для Wayland без зависимостей от GTK и Qt. Классическая
раскладка в духе Dolphin, но без перегруженности: панель быстрого доступа и
дисков слева, список файлов справа, статусная строка снизу. Оформление —
Catppuccin (Mocha по умолчанию) с переключением тем на лету.

Копирование и перемещение выполняет отдельный фоновый процесс: окно можно
закрыть в любой момент, операция не прервётся, а новый экземпляр менеджера
подключится к службе и покажет актуальный прогресс.

## Возможности

**Интерфейс**

* три режима отображения: «Подробно» (таблица с сортировкой по колонкам),
  «Компактно» (плотные колонки) и «Значки»;
* левая панель: стандартные каталоги пользователя (`user-dirs.dirs`), закладки
  из `~/.config/gtk-3.0/bookmarks`, собственные закладки и корзина; ниже —
  смонтированные диски с индикатором заполненности и свободным местом;
* путь в виде кликабельных сегментов, по клику на пустое место — ручной ввод;
* фильтр по имени, показ скрытых файлов, сортировка по имени/размеру/типу/дате
  с естественным порядком чисел (`файл2` перед `файл10`);
* контекстное меню, диалоги переименования, создания, удаления и свойств;
* 14 встроенных тем: четыре варианта Catppuccin, Nord, Dracula, Gruvbox,
  Tokyo Night, Kanagawa, Oxocarbon, Ferra, светлая и тёмная.

**Операции**

* копирование и перемещение — фоновые задачи с прогрессом, паузой и отменой;
* перемещение в пределах одной ФС выполняется мгновенным `rename`, между ФС —
  копированием с последующим удалением;
* копирование через `copy_file_range` (перенос данных внутри ядра) с откатом на
  обычное чтение/запись там, где вызов не поддерживается;
* сохраняются права доступа, время изменения и символические ссылки;
* конфликты имён разрешаются добавлением ` (2)`, ` (3)`, …;
* удаление в корзину по спецификации freedesktop.org (включая `.Trash-<uid>` на
  внешних носителях) и безвозвратное удаление с подтверждением.

**Зависимости.** Только Rust-крейты: [`iced`](https://iced.rs) (wgpu + winit,
нативный Wayland), `serde`, `serde_json`, `libc`. Иконки — встроенные SVG,
внешние темы иконок не нужны. Для открытия файлов во внешних программах
используется `xdg-open`.

## Сборка и установка

```bash
cargo build --release
```

```bash
install -Dm755 target/release/file-man ~/.local/bin/file-man
install -Dm644 assets/file-man.desktop ~/.local/share/applications/file-man.desktop
```

Запуск: `file-man [ПАПКА]`. Аргумент может быть путём или `file://`-ссылкой;
если указан файл, откроется содержащая его папка.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Enter` | открыть выделенное |
| `Backspace` | на уровень вверх |
| `Alt+←` / `Alt+→` | назад / вперёд по истории |
| `F5` | обновить |
| `F2` | переименовать |
| `Delete` | в корзину |
| `Shift+Delete` | удалить безвозвратно |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | копировать / вырезать / вставить |
| `Ctrl+A` | выделить всё |
| `Ctrl+H` | скрытые файлы |
| `Ctrl+F` | фильтр по имени |
| `Ctrl+L` | ручной ввод пути |
| `Ctrl+D` | добавить папку в быстрый доступ |
| `Ctrl+N` | создать папку |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | режимы «Подробно» / «Компактно» / «Значки» |
| `Ctrl`+клик, `Shift`+клик | добавить к выделению, выделить диапазон |
| `Escape` | снять выделение, закрыть меню или диалог |

## Как устроено фоновое копирование

```
   GUI (file-man)                     служба (file-man --copy-daemon)
        │                                        │
        │  JSON-строки поверх unix-сокета         │  поток на каждую задачу:
        │  $XDG_RUNTIME_DIR/file-man/copyd.sock   │  обход дерева → копирование
        │                                        │
        ├── Submit ──────────────────────────────▶│  (прогресс раз в ~120 мс)
        ├── Subscribe ───────────────────────────▶│
        │◀── Snapshot / Updated / Removed ────────┤
        └── Cancel / Pause / Resume ─────────────▶│
```

* служба запускается автоматически при первой операции; `setsid` отвязывает её
  от сеанса GUI, поэтому закрытие окна её не касается;
* единственность экземпляра обеспечивает `flock` на `copyd.lock`;
* при подключении клиент сразу получает снимок всех задач — поэтому новое окно
  показывает корректный статус уже идущего копирования;
* без клиентов и активных задач служба завершается через 90 секунд.

Состояние задачи (`Scanning` → `Running`/`Paused` → `Done`/`Cancelled`/`Failed`)
включает объём, число объётов, скорость и оценку оставшегося времени. Ошибки по
отдельным файлам не прерывают задачу: они собираются в список и показываются в
окне «Фоновые задачи».

## Настройки

`~/.config/file-man/config.json` — тема, режим отображения, сортировка, показ
скрытых файлов, размер окна, закладки и последний открытый каталог. Файл
переписывается приложением, но его можно править вручную при закрытом окне.

## Структура исходников

| Путь | Назначение |
| --- | --- |
| `src/ipc.rs` | протокол и клиентская часть связи со службой |
| `src/jobs/daemon.rs` | сервер службы: реестр задач, подписки, время простоя |
| `src/jobs/engine.rs` | движок копирования: обход, прогресс, пауза, отмена |
| `src/fsops/` | чтение каталогов, места и диски, корзина и операции |
| `src/ui/` | состояние, сообщения и представления (панели, диалоги, иконки) |
| `src/config.rs` | сохраняемые настройки и список тем |
